# Purchase through Discord

Paid files are never attached to this public GitHub repository.

## Order process

1. Join the official Georg Space Discord using the link in the main README.
2. Open a purchase ticket.
3. Copy and complete the order template below.
4. Wait for compatibility confirmation and the final price.
5. Pay only using the PayPal instructions posted inside that ticket.
6. After payment confirmation, the files are delivered privately in the ticket.

## Order template

```text
Plugin:
Minecraft/Paper version:
Java version:
Server software:
Installed dependencies:
Server network name:
Do you need installation help? Yes/No
```

## Safety

- Never pay through a random direct message.
- Never send account passwords or login codes.
- The public GitHub repository contains no paid JAR or source-code downloads.
- Confirm the plugin version and required dependencies before payment.

## Delivery

Delivery can contain the compiled JAR, configuration, setup guide and an included resource pack when required. Source code is not part of a normal purchase.
