# Plugin Catalog

All prices are one-time prices for one Minecraft server network. Compatibility is stated only where it has been confirmed from an existing build.

## NeonSpaceCore — €14.99

An all-in-one presentation and interaction system for NeonSpace-style servers.

**Highlights**

- Modern game and server menus
- Configurable villager interactions
- One-time rewards
- Music controls and resource-pack integration
- Custom Escape-menu logo and button text assets
- Combined distributions such as `NeonSpaceCore 4.3.1 ALL-IN-ONE`

**Includes:** JAR, configuration and the matching resource pack where required.  
**Target:** Paper 26.1.2.

## NeonPlotAddon — €14.99

A large PlotSquared expansion inspired by modern CityBuild networks.

**Highlights**

- Plot likes and purchasable like credits
- Liked-plots GUI and teleportation
- Plot warps, ratings and random plot-world teleportation
- Rank-based plot limits
- Plot flight, delete and enlarge tools
- Border shop, animated sign shops and block-action bindings
- English player messages and separate permissions

**Confirmed build:** 1.5.0 for Paper 26.1.2.  
**Dependency:** PlotSquared. Some features may require Vault/LuckPerms.

## NeonSpace Servers — €14.99

A Minehut-style server/world system with modern Paper dialogs.

**Highlights**

- `/servers` and `/customserver`
- Search, categories, favorites and history
- Visibility and allowlist controls
- Visitor protection
- World-only kick, ban and temporary-ban tools
- Team and operator protection
- Temporary bans limited to a maximum of two days

**Confirmed build:** 1.2.0.  
**Target:** Paper 26.1 / 26.1.2, Java 25.  
**Not included:** role management or server-stop controls.
